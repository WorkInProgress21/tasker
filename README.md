tasker is a Task Tracker that solely runs in the CLI. 

To install, donwload the .zip from releases, unzip it, store it simewhere safe and add it to the PATH variable.

Commands:
tasker add [Name] .... adds a Task
tasker rm  [ID] ...... removes a Task
tasker mc  [ID] ...... marks a Task as complete
tasker umc [ID] ...... unmarks a Task
tasker ls ............ lists a Task
